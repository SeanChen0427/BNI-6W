API 設定
如何取得 Gemini API Key
1
點擊下方按鈕，前往 Google AI Studio（需登入 Google 帳號）
2
登入後，點左側選單的 「Get API key」，再點 「Create API key」
3
選擇任一專案（或建立新專案），點 「Create API key in existing project」
4
畫面出現以 AIza 開頭的金鑰，點旁邊的複製圖示複製全段文字
5
回到此頁面，貼入上方的 「Gemini API Key」 欄位；私人裝置可勾選「記住 API Key」
前往 Google AI Studio 取得 API Key
API Key 只會傳送至 Google Gemini API。勾選「記住」後才會儲存在此瀏覽器的 localStorage；共用裝置請勿勾選。
